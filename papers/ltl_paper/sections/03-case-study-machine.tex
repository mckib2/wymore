\subsection{Coupled Architecture: From Infinite-Tape Idealization to Finite Buildable Modes}
\label{sec:case-machine}

We model a streaming run-length encoder as a coupled system assembled from four elementary discrete components in a technology catalog $TYR$: an input \emph{tape} ($Z_0$), a phase-clock \emph{head} ($Z_1$), an output \emph{register} ($Z_2$), and an \emph{instruction table} ($Z_3$). Table~\ref{tab:rle-components} summarizes each component's behavior, and Figure~\ref{fig:rle-architecture} depicts the system coupling recipe $SCR$.

As shown in Figure~\ref{fig:rle-architecture}, the coupling recipe $SCR$ connects the tape's output port to the instruction table's input port, connects the instruction table's output port to the register's input port, and closes the head's auxiliary port with a self-loop. This leaves a single free system input (the external bit stream $f(t)$ arriving at the tape) and a single free system output (the encoded pair $y(t)=(\text{bit},\text{count})$ emitted by the register).

\subsubsection{Stage 1: Idealized Infinite-Tape Specification (\texorpdfstring{$IOR_\infty$}{IOR\_inf})}
\label{sec:case-machine-reference}
In a top-down systems engineering workflow, the analyst first specifies the idealized mathematical behavior on an unbounded stream of binary inputs $f:\mathbb{N}\to\{0,1\}$ with no upper bound on run length ($\mathrm{count}\in\mathbb{N}$). One input symbol is sampled per two-tick sense/act cycle, so the $k$-th sampled symbol is $f(2k)$. Comparing consecutive sampled symbols defines the idealized unbounded run-length recurrence:
\begin{equation}
\begin{aligned}
  \mathrm{runLen}_\infty(f,0) &= 1, \\
  \mathrm{runLen}_\infty(f,k{+}1) &=
  \begin{cases}
    \mathrm{runLen}_\infty(f,k)+1, & f\bigl(2(k{+}1)\bigr)=f(2k),\\
    1, & \text{otherwise.}
  \end{cases}
\end{aligned}
  \label{eq:rle-inf-recurrence}
\end{equation}
At the table level, the unshifted trajectory $\phi_{\mathrm{out},\infty}(f,t)$ starts at $(0,0)$ for $t=0$, emits $\bigl(f(2k),\mathrm{runLen}_\infty(f,k)\bigr)$ on act completion tick $2k+1$, and holds that pair on sense tick $2k+2$.

However, in the coupled resultant $\mathrm{RSY}(SCR)$, synchronous Moore communication across the two internal wires (\texttt{tape} $\to$ \texttt{table} and \texttt{table} $\to$ \texttt{register}) introduces a two-tick pipeline shift between the external tape input and the external register output. Incorporating this architectural pipeline delay into the boundary specification yields the characteristic temporal formula for the idealized pipeline requirement $IOR_\infty$:
\begin{equation}
  \Phi_{IOR_\infty}(f,y)
  \;\Longleftrightarrow\;
  G\left(
  y(t)=
  \begin{cases}
    (0,0), & t<2,\\
    \phi_{\mathrm{out},\infty}(f,t-2), & t\ge 2.
  \end{cases}
  \right)
  \label{eq:phi-ior-inf}
\end{equation}
For example, when input symbols $0,0,1$ arrive at ticks $0,2,4$, the register outputs $(0,0)$ during startup ticks $0,1,2$ and then emits $(0,1)$, $(0,2)$, and $(1,1)$ at ticks $3,5,7$ (holding each pair across the subsequent even tick). While $IOR_\infty$ and its unbounded resultant $Z_{b,\infty}$ provide a clean mathematical baseline, their state spaces are countably infinite ($\mathrm{count}\in\mathbb{N}$) and therefore cannot be fabricated in finite hardware or exhaustively checked by a finite-state model checker.

\subsubsection{Stage 2: Refinement to a Finite-Tape Buildable Machine (\texorpdfstring{$Z_{b,N}$ and $Z_{m,N}$}{Zb,N and Zm,N})}
\label{sec:case-machine-zones}
To move from an idealized infinite-state model to a physically buildable machine, the engineer refines the technology catalog to $TYR_N$, where the counter register in each component has a finite hardware capacity $N\ge 1$ ($\mathrm{count}\in\{0,1,\dots,N\}$). Correspondingly, the refined boundary requirement $IOR_N$ caps consecutive run counts at saturating capacity $N$:
\begin{equation}
\begin{aligned}
  \mathrm{runLen}_N(f,0) &= \min(1,N), \\
  \mathrm{runLen}_N(f,k{+}1) &=
  \begin{cases}
    \min(\mathrm{runLen}_N(f,k){+}1,N),\\
    \hspace{2.5em}\text{if } f(2k{+}2)=f(2k),\\
    \min(1,N),\quad \text{otherwise.}
  \end{cases}
\end{aligned}
  \label{eq:rle-fin-recurrence}
\end{equation}
Notice that for every input run of length at most $N$, the finite-tape trajectory $\phi_{\mathrm{out},N}(f,t)$ is identical to the unbounded trajectory $\phi_{\mathrm{out},\infty}(f,t)$, while runs exceeding $N$ saturate cleanly at $N$.

Because every component $Z_{0,N},Z_{1,N},Z_{2,N},Z_{3,N}\in TYR_N$ is now a finite discrete system, the coupled resultant $Z_{b,N}=\mathrm{RSY}(SCR_N)\in\mathrm{CTL}(TYR_N)$ is a finite-state machine. Furthermore, when initialized in its all-zero reset configuration $s_{b,0}$, the resultant's reachable operational behavior forms a finite system mode $Z_{m,N}\in\mathrm{SYSMO}(Z_{b,N})$ whose state space $S_{m,N}$ is a small fraction of the full Cartesian product $\prod_{i=0}^3 S_{i,N}$ (for example, at capacity $N=3$, the full resultant has $512$ states while the active system mode $Z_{m,3}$ has only $43$ reachable states).

By Theorem~\ref{thm:mode-ior-bridge} and Theorem~\ref{thm:dynamics-characterization}, we can now certify that $(D_{\mathrm{ref},N},Z_{b,N})$ belongs to the implementability cotyledon $\mathrm{CTL}(IOR_N,TYR_N)$ either by checking $Z_{m,N}\models_{IO}\Phi_{IOR_N}$ directly on the boundary ports or by checking $Z_{m,N}\models_{\mathrm{dyn}}\Phi_{\mathrm{dyn}}(Z_{\mathrm{ref},N})$ against the pipeline reference design $Z_{\mathrm{ref},N}\in\mathrm{CTL}(IOR_N)$.
