\subsection{Coupled Architecture and Finite-Tape Refinement}
\label{sec:case-machine}

Each input symbol is sampled and processed across a two-phase sense/act cycle, emitting a pair $(\text{bit},\text{count})$ that records how many consecutive identical symbols have been observed. Table~\ref{tab:rle-components} summarizes each component's transition and readout behavior, and Figure~\ref{fig:rle-architecture} depicts the system coupling recipe $SCR$.

As shown in Figure~\ref{fig:rle-architecture}, the coupling recipe $SCR$ connects the tape's output port to the instruction table's input port, connects the instruction table's output port to the output register's input port, and closes the head's port with a self-loop. In Wymore's coupling recipe algebra, the connectivity relation $CSCR$ is a one-to-one port map on single-port components, and any port left unwired by $CSCR$ is automatically exposed as an external system boundary port ($\mathrm{UISCR}$ or $\mathrm{UOSCR}$). Closing the head's port with a self-loop keeps the phase clock internal to the resultant, leaving only the tape input $f(t)$ and register output $y(t)$ on the external system boundary. Critically, phase is \emph{not} communicated from $Z_1$ to $Z_3$ by a $CSCR$ wire: each of $Z_1$ and $Z_3$ maintains its own local phase bit, and the dashed annotation in Figure~\ref{fig:rle-architecture} records that these bits stay synchronized because the synchronous resultant $\mathrm{RSY}(SCR)$ steps every component on the shared global discrete clock $t\in\mathbb{N}$. The head $Z_1$ therefore supplies an observable phase signal for boundary checking (e.g., $\varphi_{\mathrm{mode}}$), while the instruction table's updates are driven by its own lock-step phase state.

\subsubsection{Stage 1: Idealized Infinite-Tape Specification (\texorpdfstring{$IOR_\infty$}{IOR\_inf})}
\label{sec:case-machine-reference}
In the initial specification stage, we define the idealized mathematical behavior on an unbounded stream of binary inputs $f:\mathbb{N}\to\{0,1\}$ with no upper bound on run length ($\mathrm{count}\in\mathbb{N}$). One input symbol is sampled per two-tick sense/act cycle, so the $k$-th sampled symbol is $f(2k)$. Comparing consecutive sampled symbols defines the recurrence:
\begin{equation}
\begin{aligned}
  \ell_\infty(f,0) &= 1, \\
  \ell_\infty(f,k{+}1) &=
  \begin{cases}
    \ell_\infty(f,k)+1, & f\bigl(2(k{+}1)\bigr)=f(2k),\\
    1, & \text{otherwise.}
  \end{cases}
\end{aligned}
  \label{eq:rle-inf-recurrence}
\end{equation}
At the instruction table level, the unshifted trajectory $\phi_{\mathrm{out},\infty}(f,t)$ starts at $(0,0)$ for $t=0$, emits $\bigl(f(2k),\ell_\infty(f,k)\bigr)$ on act completion tick $2k+1$, and holds that pair on sense tick $2k+2$.

In the coupled resultant $\mathrm{RSY}(SCR)$, synchronous Moore communication across the two internal connections (from input tape to instruction table and from instruction table to output register) introduces a two-stage Moore pipeline. Relative to the table-level trajectory $\phi_{\mathrm{out},\infty}$, this shifts the external register output by two ticks ($y(t)=\phi_{\mathrm{out},\infty}(f,t-2)$ for $t\ge 2$). End-to-end, a sampled input $f(2k)$ reaches the boundary register only at tick $2k+3$ (three ticks), because $\phi_{\mathrm{out},\infty}$ already accounts for one table-update tick. Incorporating the two-tick shift of $\phi_{\mathrm{out},\infty}$ into the boundary requirement yields the trajectory predicate $A_{IOR_\infty}(f,y)$ of the idealized boundary specification $\Phi_{IOR_\infty}$:
\begin{equation}
  A_{IOR_\infty}(f,y)
  \;\Longleftrightarrow\;
  G\left(
  y(t)=
  \begin{cases}
    (0,0), & t<2,\\
    \phi_{\mathrm{out},\infty}(f,t-2), & t\ge 2.
  \end{cases}
  \right)
  \label{eq:phi-ior-inf}
\end{equation}
Because $\phi_{\mathrm{out},\infty}(f,0)=(0,0)$, the case $t\ge 2$ also forces $y(2)=(0,0)$, so the register emits the idle pair $(0,0)$ throughout the three-tick startup window $t=0,1,2$. For example, when input symbols $0,0,1$ arrive at ticks $0,2,4$, the output register emits $(0,0)$ during those startup ticks and then emits $(0,1)$, $(0,2)$, and $(1,1)$ at ticks $3,5,7$ (holding each pair across the subsequent even tick). While $IOR_\infty$ and its unbounded resultant $Z_{b,\infty}$ provide a clean mathematical baseline, their state spaces are countably infinite ($\mathrm{count}\in\mathbb{N}$) and therefore cannot be realized in finite digital hardware or exhaustively checked by a finite-state model checker.

\subsubsection{Stage 2: Buildable Finite-Tape Machine (\texorpdfstring{$Z_{b,N}$ and $Z_{m,N}$}{Zb,N and Zm,N})}
\label{sec:case-machine-zones}
To move from the idealized specification to a physically buildable machine, we refine the technology catalog to $TYR_N$, where the counter register in each component has a finite hardware capacity $N\ge 1$ ($\mathrm{count}\in\{0,1,\dots,N\}$). Correspondingly, the refined boundary requirement $IOR_N$ caps consecutive run counts at saturating capacity $N$:
\begin{equation}
\begin{aligned}
  \ell_N(f,0) &= \min(1,N), \\
  \ell_N(f,k{+}1) &=
  \begin{cases}
    \min(\ell_N(f,k){+}1,N),\\
    \hspace{2.5em}\text{if } f(2k{+}2)=f(2k),\\
    \min(1,N),\quad \text{otherwise.}
  \end{cases}
\end{aligned}
  \label{eq:rle-fin-recurrence}
\end{equation}
For every input run of length at most $N$, the finite-tape trajectory $\phi_{\mathrm{out},N}(f,t)$ is identical to the unbounded trajectory $\phi_{\mathrm{out},\infty}(f,t)$, while runs exceeding $N$ saturate at $N$.

Figure~\ref{fig:rle-timing} traces the tick-by-tick signal propagation across the coupled RLE machine for the example input sequence $0,0,1$. At tick $t=2k$, the external input bit $f(2k)$ arrives at the tape and is latched at $2k+1$. During tick $2k+1$, the instruction table samples the tape's output on its sense phase ($c=0$), and on the subsequent act transition ($c=1$) produces the updated pair $(f(2k),\ell_N(f,k))$ in its readout at $2k+2$. During tick $2k+2$, the output register latches that pair, making it visible at the external boundary output $y(2k+3)$ and holding it through $y(2k+4)$. Because a classical Wymore homomorphism is step-synchronous, equating one clock tick of the operational mode $Z_m$ with one clock tick of the functional design $Z_f$, any boundary specification or reference design must reflect both the two-phase sense/act clock discipline and the internal pipeline latency of the coupled architecture. If a specification assumes an unshifted, single-tick clock discipline that updates on every tick, no lock-step homomorphism can exist.

Because every component $Z_{0,N},Z_{1,N},Z_{2,N},Z_{3,N}\in TYR_N$ is a finite discrete system, the coupled resultant $Z_{b,N}=\mathrm{RSY}(SCR_N)\in\mathrm{CTL}(TYR_N)$ is a finite-state machine. Furthermore, when initialized in its all-zero reset configuration $s_{b,0}$, the resultant's reachable operational behavior forms a finite system mode $Z_{m,N}\in\mathrm{SYSMO}(Z_{b,N})$ whose state space $S_{m,N}$ is a fraction of the full Cartesian product $\prod_{i=0}^3 S_{i,N}$ (for example, at capacity $N=3$, the full resultant has $512$ states whereas the active system mode $Z_{m,3}$ has $43$ reachable states). By Theorem~\ref{thm:mode-ior-bridge} and Theorem~\ref{thm:dynamics-characterization}, we can certify that $(D_{\mathrm{ref},N},Z_{b,N})$ belongs to the implementability cotyledon $\mathrm{CTL}(IOR_N,TYR_N)$ either by checking $Z_{m,N}\models_{IO}\Phi_{IOR_N}$ directly on the boundary ports or by checking $Z_{m,N}\models_{\mathrm{dyn}}\Phi_{\mathrm{dyn}}(Z_{\mathrm{ref},N})$ against the pipeline reference design $Z_{\mathrm{ref},N}\in\mathrm{CTL}(IOR_N)$.
