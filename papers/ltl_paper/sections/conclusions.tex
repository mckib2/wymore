\section{Conclusions}

We offered an assertional reinterpretation of Wymore's Functionality Cotyledon in which functional intent is expressed as a dynamics-encoding temporal fragment compiled from a discrete system. On that fragment---stated explicitly in Table~\ref{tab:phi-dyn-fragment}---assertional satisfaction is equivalent to classical implementability via Wymore system homomorphism, so engineers may treat property checking of the compiled fragment as the primary verification artifact rather than maintaining an explicit homomorphism through successive elaborations. A canonical FO-LTL execution encoding supports a shared vocabulary for tooling. Case studies on a ones-counter, a string recognizer, and a real-valued accumulator exhibit that maintenance pattern qualitatively, with finite-tier exhibit/verify of maps where applicable. Checking decidability requires finite projections or bounded queries; global equivalence for bare mission properties, and automatic map discovery on infinite or real state, remain outside the claims of this paper.
