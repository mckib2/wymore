\subsection{Boundary \texorpdfstring{$IOR$s}{IORs} as Temporal Logic Clauses: Empty vs.\ Infinite Functionality Cotyledons}
\label{sec:case-basics}

Theorem~\ref{thm:boundary-characteristic} applies to every Wymorian $IOR$, and when the eligibility relation $ER(f)$ is specified by temporal constraints, the characteristic boundary specification $\Phi_{IOR}$ takes the form of standard LTL formulas over boundary input trajectories $f(t)$ and output trajectories $y(t)$. Consider a ladder of three progressively richer boundary requirements over binary inputs $f:\mathbb{N}\to\{0,1\}$:
\begin{align}
 \text{Instantaneous echo ($IOR_{\mathrm{echo}}$):}\quad
   &G\bigl(y(t)=f(t)\bigr), \label{eq:echo-phi}\\
 \text{One-tick delay ($IOR_{\mathrm{delay}}$):}\quad
   &y(0)=b_0\ \wedge\
     G\bigl(y(t{+}1)=f(t)\bigr), \label{eq:delay-phi}\\
 \text{Streaming run-length ($IOR_{\mathrm{RLE}}$):}\quad
   &G\bigl(y(t)=\phi_{\mathrm{out}}(f,t)\bigr). \label{eq:rle-phi}
\end{align}
Each temporal formula defines the trajectory predicate $A_{IOR}(f,y)\Leftrightarrow y\in ER(f)$ of $\Phi_{IOR}$.

Studying Equations~\eqref{eq:echo-phi}--\eqref{eq:delay-phi} side by side illustrates Wymore's Theorem~6.64 ($\mathrm{CTL}(IOR)$ is either empty or infinite) through a transparent temporal lens:
\begin{itemize}
    \item \textbf{Why $\mathrm{CTL}(IOR_{\mathrm{echo}})=\emptyset$:} Equation~\eqref{eq:echo-phi} demands $y(0)=f(0)$ at tick zero. However, in any Wymorian discrete system $Z=(S,I,O,\delta,\rho)$ with a fixed initial state $s_0$, the initial output $y(0)=\rho(s_0)$ is determined solely by $s_0$ before the external input $f(0)$ acts through $\delta(s_0,f(0))$ to reach $s(1)$. No single initial state $s_0$ can simultaneously produce $y(0)=0$ when $f(0)=0$ and $y(0)=1$ when $f(0)=1$. Thus $\Phi_{IOR_{\mathrm{echo}}}$ exposes an immediate causality contradiction with Moore readout semantics, and $\mathrm{CTL}(IOR_{\mathrm{echo}})$ is empty.
    \item \textbf{Why $\mathrm{CTL}(IOR_{\mathrm{delay}})$ is infinite:} Equation~\eqref{eq:delay-phi} accounts for the minimum one-tick state-transition latency by fixing a known startup output $y(0)=b_0$ and requiring $X\,y(t)=f(t)$ thereafter. A two-state 1-bit shift register satisfies $\Phi_{IOR_{\mathrm{delay}}}$, and once one functional design exists, $\mathrm{CTL}(IOR_{\mathrm{delay}})$ contains infinitely many isomorphic and elaborated systems.
\end{itemize}
For the streaming run-length requirement~\eqref{eq:rle-phi}, each input symbol is sampled and processed across a two-phase sense/act cycle, emitting a pair $(\text{bit},\text{count})$ that tracks how many consecutive identical symbols have been observed. As with $IOR_{\mathrm{delay}}$, the multi-stage pipeline latency of the coupled hardware architecture must be reflected in $\Phi_{IOR_{\mathrm{RLE}}}$ so that the boundary specification is causally realizable.
