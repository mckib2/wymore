\section{Conclusion}
\label{sec:conclusions}

We have established a formal correspondence between Wymore's Tricotyledon Theory of System Design (T3SD) and temporal logic that brings automated model checking into T3SD without altering its systems-theoretic foundations. We showed that every Wymorian input/output requirement $IOR$ translates into a characteristic boundary temporal specification $\Phi_{IOR}$ whose assertional functionality space $\mathrm{AFSR}(\Phi_{IOR})$ is in canonical bijection with the functionality cotyledon $\mathrm{CTL}(IOR)$ (Theorem~\ref{thm:boundary-characteristic}). Building on this correspondence, we proved that an operational system mode $Z_m\in\mathrm{SYSMO}(Z_b)$ of a buildable resultant $Z_b=\mathrm{RSY}(SCR)\in\mathrm{CTL}(TYR)$ admits an identity-boundary homomorphism onto a functional design in $\mathrm{CTL}(IOR)$ if and only if $Z_m\models_{IO}\Phi_{IOR}$ directly (Theorem~\ref{thm:mode-ior-bridge}), and admits a surjective homomorphism onto a specific reference machine $Z_{\mathrm{ref}}\in\mathrm{CTL}(IOR)$ if and only if $Z_m\models_{\mathrm{dyn}}\Phi_{\mathrm{dyn}}(Z_{\mathrm{ref}})$ (Theorem~\ref{thm:dynamics-characterization}). These results replace manual homomorphism construction and maintenance with temporal logic verification while preserving conformance across isomorphic state re-encodings, port relabelings, and compositional couplings (Theorems~\ref{thm:encoding-invariance}--\ref{thm:finite-canonicity}).

Through the RLE case study, we demonstrated how the reinterpretation of the functionality cotyledon as a temporal specification operates across a top-down systems engineering workflow. Starting from an idealized infinite-tape requirement $IOR_\infty$, we refined the architecture to a family of finite-tape buildable machines $Z_{b,N}=\mathrm{RSY}(SCR_N)$ assembled from four coupled components (input tape, sense/act head, output register, and instruction table). Because every component in the finite-capacity catalog $TYR_N$ is a finite discrete system, isolating the reachable operational mode $Z_{m,N}\in\mathrm{SYSMO}(Z_{b,N})$ yields a finite Kripke structure on which propositional LTL model checking is decidable and efficient. Across nine configurations, an automated LTL checker certified conformance across increasing tape capacities, verified state-re-encoded and diagnostically instrumented component revisions without modifying the boundary specification, and identified the violated temporal clauses in faulty and timing-mismatched designs.

Several directions for future work follow naturally from these results. First, relaxing Wymore's lock-step single-tick homomorphisms to multi-rate and stuttering implementation relations (characterizable in LTL without the next-step operator $X$ \citep{Lamport2002,BrowneClarkeGrumberg1988}) would allow pipelined and multi-phase buildable modes to be verified directly against unpipelined abstract specifications. Second, while the compiled dynamics fragment $\Phi_{\mathrm{dyn}}$ uses only invariant and next-step operators ($G$ and $X$) to mirror Wymore's step-local homomorphism laws, richer temporal liveness requirements ($F\,\varphi$, $GF\,\varphi$) and quantitative or real-time temporal logics can be incorporated into $\Phi_{IOR}$ to express fairness constraints and preference orderings over the implementability cotyledon $\mathrm{CTL}(IOR,TYR)$. Finally, coupling the compositional propagation theorem (Theorem~\ref{thm:elaboration-coupling}) with symbolic BDD and SAT/SMT-based model checkers such as NuSMV/nuXmv \citep{CavadaEtAl2014} offers a pathway to scale T3SD verification to large industrial coupling recipes by verifying component modes locally before propagating conformance to the coupled resultant.
