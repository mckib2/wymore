\section{Introduction}

Adequately formulating and verifying functional intent before committing to implementations is a core principle of systems engineering \citep{salado2019mbse}. Model-Based Systems Engineering (MBSE) aims to make that intent precise and checkable, yet many requirements remain informal statements or diagrams whose conformance arguments are reconstructed by hand.

Wymore's Tricotyledon Theory of System Design (T3SD) supplies a mathematical account of design spaces---Functionality, Buildability, and Implementability---together with trajectory theorems and constructive verification via reference systems and system homomorphisms \citep{Wymore1993,salado2019wymore}. In classical practice, functional intent is formalized as a reference system $Z_{\text{spec}}$ in the Functionality Cotyledon (FC), and a buildable system $Z_{\text{impl}}$ is accepted when a Wymore system homomorphism into $Z_{\text{spec}}$ can be exhibited. Constructing and maintaining such homomorphisms is laborious when buildable structure evolves, because the witness is tied to particular state and interface encodings.

We contend that elements of the FC can be reinterpreted assertionally as temporal property sets over Wymore trajectories while preserving the cotyledon structure of the theory. The central proposition of this paper is that functional intent may be compiled from a Wymore discrete system (DSYSTEM) into a \emph{dynamics-encoding} temporal fragment $\Phi_{\mathrm{dyn}}$, and that on this fragment, assertional satisfaction is equivalent to classical implementability via Wymore system homomorphism. Consequently, system modelers need not maintain explicit homomorphisms as the primary verification artifact: re-checking $\Phi_{\mathrm{dyn}}$ against a revised buildable system answers the same implementability question. Modelers may also author properties directly, including liveness formulas outside $\Phi_{\mathrm{dyn}}$, without needing to first model a reference system. The bi-implication applies directly when the authored set is a complete dynamics-encoding fragment.

\miniheading{Contributions}
\begin{itemize}
    \item An assertional reading of the Functionality Cotyledon, with a dynamics-encoding bridge compiled from $Z_{\text{spec}}$ and allowable extensions to properties beyond that fragment.
    \item A formal proof of equivalence, on the dynamics-encoding fragment, between assertional satisfaction and classical implementability via Wymore system homomorphism.
    \item Case studies that illustrate maintenance of one $\Phi_{\mathrm{dyn}}$ across evolving and increasingly complex buildable systems.
\end{itemize}
