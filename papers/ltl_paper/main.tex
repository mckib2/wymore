\abstract{%
In Wymore's Tricotyledon Theory of System Design (T3SD), an input/output requirement (IOR) defines the functionality cotyledon of systems satisfying desired boundary trajectories, while a set of technologies along with coupling recipes define the buildability cotyledon of component architectures. Certifying implementability requires isolating an operational mode of a buildable design and exhibiting a surjective homomorphism that maps onto a functional design, a manual process that becomes arduous for highly coupled systems and lacks automated tooling. This paper develops a correspondance between T3SD and temporal logic to enable automated model checking within Wymore's framework. First, we prove that every IOR is isomorphic to a boundary specification in temporal logic. Second, we show that certifying a buildable system mode reduces to checking temporal specifications directly, avoiding manual homomorphism construction while preserving conformance across state re-encodings and component elaborations. Because buildable components are generally finite-state, Linear Temporal Logic (LTL) model checking over their operational modes is decidable and automated, which we demonstrate by building a run-length encoder specification using a finite-tape machine.%
}
