\begin{abstract}
\sloppy
In Wymore's Tricotyledon Theory of System Design (T3SD), an input/output requirement defines the functionality cotyledon of systems satisfying desired boundary trajectories, while a technology catalog and coupling recipe define the buildability cotyledon of component architectures. Certifying implementability requires isolating an operational mode of a buildable design and exhibiting a surjective homomorphism onto a functional design---a manual process that is arduous for coupled systems and lacks automated tooling. This paper bridges T3SD and temporal logic to bring automated model checking into Wymore's framework. First, we prove every Wymorian input/output requirement is isomorphic to a boundary specification in temporal logic. Second, we show certifying a buildable system mode reduces to checking temporal specifications directly, avoiding manual homomorphism search while preserving conformance across state re-encodings and component elaborations. Because buildable components are finite-state, Linear Temporal Logic (LTL) model checking over their modes is decidable and automated, demonstrated by refining an infinite-tape run-length encoder into a verified finite-tape machine.

\keywords{Tricotyledon Theory of System Design (T3SD), Linear Temporal Logic (LTL), formal verification, Model-Based Systems Engineering (MBSE), system homomorphism, system modes.}
\end{abstract}
