\miniheading{Abstract}
We propose an assertional reinterpretation of the Functionality Cotyledon in A.\ Wayne Wymore's Tricotyledon Theory of System Design (T3SD). In classical T3SD, functional intent is verified constructively between a reference system and implementation via Wymore system homomorphism. We offer an assertional reading of the FC as $\mathcal{FC}_{\mathcal{L}}(\Phi) = \{ Z \mid Z \models_{\mathcal{L}} \Phi \}$, where $\Phi$ is a set of temporal logic properties over Wymore discrete-system trajectories and $\mathcal{L}$ is a chosen temporal logic dialect (FO-LTL in the encoding theorem). We show that any Wymore DSYSTEM admits a canonical FO-LTL encoding of its execution semantics, enabling solver-based property checking as an alternative to manual or interactive homomorphism proofs (in decidable or bounded fragments). The contribution is a reinterpretation of the elements of the Functionality Cotyledon, trace semantics, encoding methodology, and workflow comparison.

\paragraph{Keywords}
Tricotyledon Theory of System Design (T3SD), First-Order Linear Temporal Logic (FO-LTL), Formal Verification, Model-Based Systems Engineering (MBSE).
