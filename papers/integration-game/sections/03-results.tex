\section{Results} \label{sec:results}

To evaluate our proposed methodology across our three research questions, we developed a reference implementation in Python paired with the Z3 SMT solver~\cite{deMouraZ32008} as the symbolic backend.  The implementation realizes Color $\kappa$, the configurable Technology Catalog $TYR_{\mathcal{K}}$, synchronous discrete-time simulation of the Coupled Resultant $Z_b = \mathrm{RSY}(\mathcal{P})$, single- and multi-Consumer uLSC monitors compiled into Reward Machines, symbolic fragment verification, and the offline and online Markov Decision Process environments.

\subsection{Progressive Verification Suite (Scenarios S1--S15)} \label{sec:res-catalog}

We designed a fifteen-scenario verification suite (Scenarios S1--S15) that systematically isolates canonical systems-integration anomalies across Color axes and stateful behavioral contracts (with Scenario S15 reserved as an unseen industrial avionics holdout).  Each scenario begins with incompatible Producer Offers and Consumer Needs, exposes deceptive Tier~3 behavioral traps (e.g., lower-cost Mediation Operators that satisfy Tier~1 Color alignment and Tier~2 kinematic compatibility but violate trajectory-level obligations) and admits a verified winning Play:

\begin{itemize}[leftmargin=1.5em,itemsep=2pt]
  \item \textbf{Closed-Loop Autonomy (S1) \& Causal Ping-Pong Handshake (S2):}
        Evaluates autonomous feedback coupling and push-to-pull queue mediation in which a retain-on-read latch violates quiet-tick silence obligations, whereas a consume-on-read FIFO queue satisfies the uLSC Main-Chart.
  \item \textbf{Multi-Representation Gateway (S4) \& Hierarchical Entity Recoloring (S5):}
        Evaluates multi-hop runtime ABI marshaling ($\Delta\rho$; e.g., C-ABI $\leftrightarrow$ Python-object $\leftrightarrow$ DDS language binding) together with UDDL entity-composition projection and affine thermal conversion ($\Delta C, \Delta L, \Delta P$). Route Carriers handle bus/transport edges; uncalibrated identity casts that ignore ABI mismatch pass superficial typing but trigger Hot Breaches on the value envelope.
  \item \textbf{Dynamic State Estimation (S3), Non-Commutative Derivation (S6) \& Hard Deadline Synthesis (S7):}
        Evaluates multi-input computational derivations where naive finite-difference estimators, swapped-operand kinetic-energy derivations ($\frac{1}{2}v m^2$ versus $\frac{1}{2}m v^2$), or high-latency batch solvers satisfy static port typing but breach accuracy or deadline invariants.
  \item \textbf{Multi-Consumer Fan-Out (S8), Multi-Rate Clock Bridging (S9) \& Temporal Window Join (S11):}
        Evaluates composite multi-Consumer uLSC contracts, multi-rate mediation across stores, pumps, and freshness gates, and bounded-window correlation across asynchronous streams.
  \item \textbf{Provenance Triple-Modular Redundancy (S10), Redundant Link Failover (S12), Stateful Transaction FSM (S13) \& Pareto Trade Study (S14):}
        Evaluates provenance-weighted majority voting, runtime failover multiplexing between primary and backup Route Carriers, stateful accumulation with silence invariants prior to threshold fulfillment, and multi-objective Pareto trade-offs across competing winning architectures.
  \item \textbf{Avionics Multi-Bus Holdout (S15):}
        Models a FACE/SOSA-inspired avionics integration that couples navigation telemetry over a MIL-STD-1553 Route Carrier to an on-demand DDS guidance Consumer, requiring ABI marshaling $\Delta\rho$, coordinate-frame recoloring $\Delta L$, and push-to-pull mediation as an external generalization holdout.
\end{itemize}

\subsection{Cost Axiom Verification, Sensitivity Analysis, and Symbolic CEGIS} \label{sec:res-cost}

Auditing $\mathcal{J}$ and $\mathcal{S}$ against Axioms~(A1)--(A7) on S1--S14 and a 16-point weight grid confirms all axioms hold.  \emph{Feasibility Dominance} (A1) with $\Omega = 10^{4}$ separates $\max\mathcal{J}_{\text{win}} = 6.30 < \min\mathcal{J}_{\text{lose}} = 10010.20$ (and $\min\mathcal{S}_{\text{win}} = 93.70 > \max\mathcal{S}_{\text{lose}} = 92.58$); on S14, $w_{\text{loss}}$ and $\gamma$ shift Pareto ranks without breaking feasibility.  On S6, a symmetric $ITR_{\text{test}}$ ($m = v$) admits a swapped-operand coincidence point; SMT/CEGIS over $\mathsf{QF\_LRA}$/$\mathsf{QF\_NRA}$/$\mathsf{QF\_LIRA}$ returns $m \neq v$ and forces the true wiring.
