\section{Implementation and Results} \label{sec:results}

We implemented a reference simulator of the Integration Game in Python
(\texttt{integration\_game}), covering the unified field ontology, the
technology catalog $\mathcal{T}$, discrete-time board simulation
$Z_b=\mathrm{RSY}(\mathrm{Board})$, a Universal LSC compiled into an explicit
Timed B\"uchi / Reward Machine monitor, and the composite cost/fitness
evaluation $J$/$S$. A first-class \texttt{Play}/\texttt{Move} API exposes the
offline synthesis action space (add operator, add route, set parameters,
finalize) with illegal-move rejection.

\subsection{Proof-of-concept catalog}

Twelve progressive scenarios exercise the claim that the game is feasible and
well-defined. Each scenario starts from mismatched Offers/Needs, admits a
sequence of legal moves, and reports per-snapshot Tier~1/2/3 penalties,
static/dynamic cost, and fitness $S=100-J_{\mathrm{soft}}$. Every scenario
terminates in a three-tier winning play. Representative traps confirm that
Tier~1+2 satisfaction is insufficient:

\begin{itemize}[leftmargin=1.5em,itemsep=2pt]
  \item \textbf{Ping/Pong:} a retain-on-read cache bridges PUSH$\to$PULL
        (Tiers~1--2) but violates hot silence; consume-on-read wins.
  \item \textbf{Piston telemetry:} a lying logical recolor that relabels Kelvin
        as Celsius passes structure/flow checks but breaches the value envelope.
  \item \textbf{Kalman Derive:} naive finite differences satisfy color contracts
        yet fail velocity tolerance; an $\alpha$--$\beta$--$\gamma$ estimator wins
        at higher static cost.
  \item \textbf{Hard latency:} a delayed heavy Derive misses same-tick deadlines;
        a cheap identity path wins.
  \item \textbf{Provenance TMR:} a single DAL-C sensor fails trust/assurance
        predicates; a three-way vote block produces $\texttt{TMR\_VOTED}$ fields
        that satisfy the Need.
\end{itemize}

Additional scenarios cover autonomous internal diagnostics, multi-representation
transcoding, ALU assemble/derive, fan-out, mismatched-rate Cache+Pump mediation,
temporal keyed join, and online Mux failover. Among winning plays, residual
cost $C_{\mathrm{static}}+C_{\mathrm{dyn}}$ ranks architectures (e.g., Kalman
vs.\ a cheaper but non-winning finite-difference board).

\subsection{Reproducibility}

The package lives under \texttt{papers/integration-game/}. Running
\begin{verbatim}
PYTHONPATH=src python -m integration_game.examples.run_progressive_examples
pytest
\end{verbatim}
reproduces the progression tables and the regression suite that asserts each
catalog example ends in a winning play and that the teaching traps fail only
(or primarily) on Tier~3.
