\section{Implementation and Results} \label{sec:results}

We implemented a modular reference simulator of the Integration Game in Python
(\texttt{integration\_game}), covering the unified field ontology, a fully
configurable parameter hierarchy (\texttt{GameConfig}, \texttt{ScoringConfig},
\texttt{CatalogCostConfig}, \texttt{ColorDistanceConfig}, and
\texttt{CarrierCostConfig}), the technology catalog $\mathcal{T}$, topological
discrete-time board simulation $Z_b=\mathrm{RSY}(\mathrm{Board})$, single- and
multi-consumer Universal LSC monitors (\texttt{UniversalLSC} and
\texttt{CompositeLSC}) compiled into explicit Timed B\"uchi / Reward Machine
automata, and the composite cost/fitness evaluator $\mathcal{J}$/$\mathcal{S}$.
A first-class \texttt{Play}/\texttt{Move} API exposes the offline synthesis
action space (add operator, add route, set parameters, finalize) with
illegal-move rejection.

\subsection{Modular Progressive Catalog (\texttt{ex01}--\texttt{ex14})}

Fourteen self-contained scenario modules (\texttt{ex01\_autonomous.py} through
\texttt{ex14\_cost\_sensitivity.py}) exercise progressive mediation across
complex color hierarchies, multi-representation transcoding, provenance voting,
and stateful behavioral synthesis. Each scenario starts from mismatched
Offers/Needs, steps through constructive moves and deceptive Tier~3 traps, and
terminates in a verified three-tier winning play:

\begin{itemize}[leftmargin=1.5em,itemsep=2pt]
  \item \textbf{Autonomous Closed-Loop Regulation (\texttt{ex01}) \& Ping/Pong (\texttt{ex02}):}
        Demonstrate autonomous feedback synthesis ($I_{\text{ext}}=\emptyset$)
        with discrete-time loop stability and Push$\to$Pull queue semantics
        where retain-on-read violates hot silence while consume-on-read wins.
  \item \textbf{Multi-Representation Gateway (\texttt{ex04}) \& Hierarchical Piston Model (\texttt{ex05}):}
        Exercise multi-hop representation bridges (\texttt{MIL\_STD\_1553} $\to$
        \texttt{NATIVE\_STRUCT} $\to$ \texttt{CDR\_DDS} and \texttt{JSON} $\to$
        \texttt{PROTOBUF}) and three-level UDDL entity hierarchies
        (\texttt{Engine.Cylinder.Piston} vs.\ \texttt{Airframe.Propulsion}) with
        record projection, disaggregation, pull-to-push pumping, and thermal synthesis.
  \item \textbf{Kalman Estimator (\texttt{ex03}), Non-Commutative ALU (\texttt{ex06}) \& Hard Latency (\texttt{ex07}):}
        Show that passing Tiers~1--2 with naive finite differences, swapped
        kinetic-energy operands ($\frac{1}{2}vm^2 \neq \frac{1}{2}mv^2$), or
        multi-tick solver delays triggers uncapped Tier~3 value or deadline
        penalties.
  \item \textbf{Multi-Consumer Fan-Out (\texttt{ex08}), Mismatched Clocks (\texttt{ex09}) \& Temporal Join (\texttt{ex11}):}
        Verify simultaneous multi-sink contracts via \texttt{CompositeLSC},
        invariant-boundary multi-rate mediation (\texttt{Cache} + \texttt{Pump} +
        \texttt{StaleGate}), and keyed temporal-window correlation across sensor skew.
  \item \textbf{Provenance TMR (\texttt{ex10}), Dynamic Failover (\texttt{ex12}) \& Stateful Vending FSM (\texttt{ex13}):}
        Demonstrate single-sensor fault masking under \texttt{TMR\_VOTED} trust
        contracts, runtime primary-to-backup link switching, and stateful
        behavioral credit accumulation where stateless assembly breaches hot silence.
\end{itemize}

\subsection{Cost Axiom Verification, Weight Sensitivity, and Z3 Symbolic/BMC Certification}

Module \texttt{sensitivity.py} provides automated verifiers for the seven
technology-independent cost assertions (A1--A7) and a one-at-a-time parameter
sensitivity sweep across $(w_{\text{color}}, w_{\text{kin}}, w_{\text{loss}},
w_{\text{lat}}, \gamma)$. Across all 14 progressive examples and 16 weight
combinations, Axioms A1--A7 hold with 100\% invariance ($\max \mathcal{J}_{\text{win}} = 6.30 < \min \mathcal{J}_{\text{lose}} = 10010.20$; $\min \mathcal{S}_{\text{win}} = 93.70 > \max \mathcal{S}_{\text{lose}} = 92.58$), while varying $w_{\text{loss}} \in [0.2, 12.0]$ and $\gamma \in [0.8, 1.0]$ smoothly shifts the Pareto ranking among winning architectures in \texttt{ex14} (minimal lossless in-process vs.\ redundant-operator vs.\ lossy narrowing vs.\ high-latency IPC).

To guard against test-scenario coincidence traps without sacrificing RL rollout speed, module \texttt{verifier.py} integrates the Z3 SMT solver across $\mathsf{QF\_LRA}$, $\mathsf{QF\_NRA}$, and $\mathsf{QF\_LIRA}$ Bounded Model Checking (BMC). In 1--8\,ms per query, Z3 universally certifies (\texttt{unsat}) the winning plays and synthesizes concrete counterexamples (\texttt{sat}) for deceptive assemblies—including refuting a $-40^\circ\text{F} = -40^\circ\text{C}$ coincidence-point unit cast (\texttt{ex05}), proving polynomial non-commutativity of $E_k = \frac{1}{2}mv^2$ vs.\ $\frac{1}{2}vm^2$ (\texttt{ex06}), and checking all $2^H$ arrival/dropout schedules and $4^H$ coin sequences for \texttt{ex02}, \texttt{ex09}, \texttt{ex10}, and \texttt{ex13}. In the closed-loop CEGIS harness (\texttt{cegis\_verify\_and\_augment\_ex06}), a weak test scenario ($m=10, v=10$) initially fooled by the swapped-operand ALU is automatically augmented with the Z3 counterexample $(m=2.0, v=1.5)$, flipping the flawed board to \texttt{UNSAT} while preserving the true winner.

\subsection{Reproducibility}

The package and 58-test verification suite live under \texttt{papers/integration-game/}. Running
\begin{verbatim}
/venvs/wymore/bin/python -m integration_game.examples.run_progressive_examples
/venvs/wymore/bin/pytest
\end{verbatim}
reproduces all 14 progression tables, the A1--A7 axiom audit, the weight sensitivity sweep, and the Z3 symbolic/BMC and CEGIS verification suite.
