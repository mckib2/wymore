\section{Conclusion} \label{sec:conclusion}

We formulated MOSA-style data and behavior mediation as the Integration Game:
a Wymorian board of Offers, Needs, and typed operators, won by simultaneous
Tier~1 (structure/color/representation/provenance), Tier~2 (kinematics), and
Tier~3 (uLSC/TBA) satisfaction and ranked by residual cost. A Python reference
implementation realizes the ontology, technology catalog, Reward Machine
monitor, and twelve progressive scenarios that demonstrate feasibility.
Future work will train offline board-synthesis and online adaptation policies
against the Reward Machine interface already exposed by the PoC.
